# خطة المثبت التلقائي على Linux والهوية البصرية — EGO Suite

> **الحالة:** مرحلة التخطيط فقط (Planning Only)

---

## 1. استراتيجية التثبيت الذاتي والتنقل بين الأجهزة (Portable Linux Bootstrapper)
لضمان أن **EGO Suite** يعمل على أي جهاز Linux لديك بمجرد نسخ المجلد أو سحبه من Git دون إعداد يدوي متعب:

### أ. آلية أمر التثبيت (`./ego-setup.sh` أو `ego install`)
1. **فحص البيئة التلقائي (Environment Preflight):**
   - التعرف على توزيعة Linux (`Ubuntu/Debian` عبر `apt`، `Fedora` عبر `dnf`، `Arch` عبر `pacman`).
   - التحقق من وجود الأساسيات (`git`, `curl`, `python3`, `docker` أو `node`/`go` عند الحاجة) وتثبيت الناقص بموافقة المستخدم.
2. **التثبيت المعزول داخل مجلد البرنامج (Self-Contained Workspace):**
   - إنشاء بيئة Python افتراضية محلية (`.venv/`) للأدوات المبنية بـ Python (`semgrep`, `bandit`, `wapiti`, `checkov`, `pip-audit`) حتى لا تتعارض مع حزم النظام.
   - إنشاء مجلد `bin/` محلي داخل **EGO Suite** لتحميل الملفات التنفيذية (Binaries) للأدوات السريعة (`nuclei`, `httpx`, `trivy`, `osv-scanner`, `gitleaks`, `bearer`, `testssl.sh`) مباشرة من إصداراتها الرسمية على GitHub مع التحقق من بصمة الملف (`SHA256 Checksum`).
   - سحب صور Docker الخاصة بالأدوات الثقيلة (`owasp-zap`, `sonarqube-scanner`, `trufflehog`) أو تشغيلها عند الطلب (`Pull-on-demand`) لتقليل المساحة عند التنقل.
3. **ملف الحالة (`ego-healthcheck`):**
   - شاشة أو أمر يتحقق من جاهزية كل أداة من الـ 19 أداة (مثبتة / غير مثبتة / تحتاج تحديث) مع زر **"تثبيت / إصلاح الكل"**.

### ب. سهولة النقل بين الأجهزة (Portability)
- قاعدة البيانات (`ego.db` - SQLite) وملفات الإعدادات (`config.yaml`) والتقارير (`reports/`) تُحفظ داخل مجلد بيانات محمول (`./data/`) داخل المشروع نفسه.
- عند الانتقال لجهاز Linux جديد: تنسخ مجلد `EGO-Suite` (مع أو بدون `data/`) وتشغّل `./ego-setup.sh` ليقوم بتجهيز نفس الأدوات والإعدادات تلقائياً في دقائق.

## 2. الهوية البصرية وتصميم الواجهة (EGO Suite — Yellow & Black Theme)

### أ. نظام الألوان المقترح (High-Contrast Cyber Amber & Obsidian)
- **الخلفية الأساسية (Obsidian Black):** `#09090B`
- **خلفية البطاقات واللوحات (Carbon Surface):** `#121216` و `#18181D`
- **الحدود والفواصل:** `#27272F` (وتتحول إلى أصفر متوهج `#FACC15` عند التحديد أو التركيز)
- **اللون الرئيسي (EGO Yellow / Amber):** `#FACC15` (للأزرار الرئيسية، الشعار، المؤشرات النشطة)
- **لون التفاعل (Hover Yellow):** `#EAB308`
- **النص على الخلفية الصفراء:** أسود داكن `#09090B` (لتحقيق أعلى تباين وقراءة مريحة للعين)
- **النصوص الأساسية:** أبيض ناصع `#FAFAFA` ونصوص ثانوية رمادية `#A1A1AA`
- **ألوان مستويات الخطورة في التقارير:**
  - `Critical`: أحمر واضح `#EF4444`
  - `High`: برتقالي `#F97316`
  - `Medium`: أصفر `EGO` `#FACC15`
  - `Low`: أزرق `#38BDF8`
  - `Fixed`: أخضر `#22C55E`

### ب. الشاشات الرئيسية في واجهة **EGO Suite**
1. **لوحة القيادة (Command Center):** ملخص المشاريع، آخر الفحوصات، ونسبة الثغرات المحلولة.
2. **شاشة الفحص الجديد (New Scan):** اختيار سريع بين **رابط حي (URL)** أو **مجلد محلي (Local Path)** + اختيار ملف التعريف (فحص سريع / فحص شامل / أدوات مخصصة).
3. **إدارة الأدوات (Tools Manager):** حالة الـ 19 أداة، أزرار التثبيت/التحديث، وتعديل إعدادات كل أداة.
4. **مركز التقارير وإعادة الاختبار (Reports & Re-test):** التقرير المجمع، الفلترة، ومقارنة الفحوصات قبل وبعد الإصلاح.
